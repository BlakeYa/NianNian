# 🏮 念念 · NianNian

> **念 念 不 忘 · 必 有 回 响**

农历生日助手 —— 把家人的农历生日装进你的日历，每年准时提醒。

---

## 📖 故事

今年我又把妈妈的生日给忘了。

不是不孝，是真的记不住。妈妈的生日是农历八月十五，每年对应的公历日期都不一样。去年是 9 月 29 日，今年是 10 月 6 日，明年又跑到 9 月 25 日了。日历 App 上设了「每年重复」，但那是按公历来的，下一年就错了。

我想在 iPhone 日历上记录农历生日，却发现没有一个简单、好看、不需要折腾的方案：

- **用 Python 脚本**？家里长辈不会。
- **用 App**？数据锁在里面，换手机就没了，也分享不了。
- **用现成的网页工具**？要一行一行在 input 框里手填，不支持批量，UI 还停留在十年前。

既然没有好用的，那我就自己做一个。

我做了「念念」—— 一个**纯前端、零隐私风险、完全免费、开源**的农历生日工具。

## 🤔 痛点

- 农历生日每年公历日期都变，系统日历的「每年重复」用不了
- 市面上的方案要么是命令行，要么 UI 简陋，要么不支持批量
- 数据隐私没保障，很多工具需要注册账号或将数据上传到服务器
- iOS / Android / Mac 之间跨平台难以同步

---

## 💡 解决方案

**念念** 帮你做一件事：用你填好的家人农历生日列表，**生成一个标准 `.ics` 日历文件**。

你只要：

```
① 在网页上填几个人的农历生日（或上传 CSV）
② 点一下「生成并下载」
③ 打开下载的 .ics 文件 → 导入日历 App
④ iCloud / Google 自动同步到所有设备
```

从此，每年农历生日那天，你的日历会自动显示，并按你设定的提前时间发通知提醒。

## 📂 CSV 格式

```csv
name,lunarMonth,lunarDay,note,daysBefore,mode
妈妈,8,15,农历八月十五,3,once
爸爸,5,5,农历五月初五,7,daily
奶奶,12,23,农历腊月廿三,7,daily
孩子,3,10,农历三月初十,1,once
```

**字段说明：**

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 姓名，会显示在日历事件标题上 |
| `lunarMonth` | ✅ | 农历月份（1-12） |
| `lunarDay` | ✅ | 农历日期（1-30） |
| `note` | | 备注，显示在事件详情中 |
| `daysBefore` | | 提前几天开始提醒（默认 1） |
| `mode` | | 提醒模式：`once` / `daily` / `everyOtherDay`（默认 `once`） |

**提醒模式说明：**

| mode | 效果 | 示例 |
|---|---|---|
| `once` | 提前 N 天提醒一次 | `daysBefore=7` → 生日前 7 天通知一次 |
| `daily` | 从提前 N 天开始，每天提醒直到生日 | `daysBefore=3` → 3 天前、2 天前、1 天前、当天 |
| `everyOtherDay` | 隔天提醒 | `daysBefore=7` → 7 天前、5 天前、3 天前、1 天前 |

## 🏗️ 技术架构

```
niannian/
├── README.md              ← 产品文档（你正在看的就是）
├── index.html             ← 单文件应用（所有代码内联）
│   ├── HTML 结构
│   ├── CSS（手写，零依赖）
│   └── JavaScript
│       ├── solarlunar.js  ← 农历转换库（内联）
│       ├── csv-parser.js  ← CSV 解析
│       ├── ics-generator.js  ← ICS 生成
│       └── pwa.js         ← Service Worker
├── manifest.json          ← PWA 配置
├── icon-192.png           ← PWA 图标
├── icon-512.png
├── sample.csv             ← 样例 CSV（供用户下载）
├── PRIVACY.md             ← 隐私声明（可选）
└── LICENSE                ← MIT
```

**关键技术决策：**

| 决策 | 选择 | 理由 |
|---|---|---|
| 架构 | **单 HTML 文件** | 可离线运行，可审计，部署简单 |
| 农历转换 | `solarlunar` **内联** | 零依赖，零网络请求，1900-2100 覆盖 |
| CSS | **手写** | 不依赖 Tailwind CDN，隐私优先 |
| 部署 | **GitHub Pages** | 免费 HTTPS，全球加速 |
| 表单持久化 | `localStorage` | 刷新/关闭不丢数据，隐私安全 |
| PWA | `Service Worker` + `manifest.json` | 可添加到主屏幕，类原生体验 |

**关于隐私的技术保障：**

- 整个应用**没有一行后端代码**
- 农历转换库直接内联在 HTML 中，**不请求任何 CDN**
- 不使用 Google Fonts、图片 CDN、分析脚本等任何**第三方资源**
- `Service Worker` 仅用于缓存应用本身，**不拦截或上传任何数据**
- 可通过 `file://` 协议本地打开，完全离线运行
