📖 导入日历指南

下载 .ics 文件后，按你的设备选择导入方式：

💡 如果已经有「念念·农历生日」日历，更新时记得先右键删除旧日历再导入新文件。分多次导入同一个日历，Apple 日历会当成不同事件重复展示。
💻

Mac

  1. 双击下载的 .ics 文件
  2. 日历 App 自动打开
  3. 选择「新建日历」命名为「念念·农历生日」
  4. 点击「好」完成导入
📱

iPhone / iPad

  1. 将 .ics 文件发到微信或邮件
  2. 点击文件 → 选择「用日历打开」
  3. 选择「新建日历」命名为「念念·农历生日」
  4. 点击「完成」→ iCloud 自动同步
🔄

如何更新 / 如何删除

  1. 在网页修改后重新生成并下载 ICS
  2. 日历 App 左侧栏右键删除旧的「念念·农历生日」日历
  3. 双击新 ICS 重新导入到同名日历
  4. iCloud 自动同步所有设备
💡 删除日历只移除生日事件，不影响其他日程。先删旧日历再导新文件，不会产生重复事件。
❓ 常见问题
🤦 导入到错误的日历了怎么办？

情况 A：导入到了独立的「念念·农历生日」日历 → 直接删除该日历即可，一秒清空。

情况 B：导入到了已有的日历（如「个人」）→ 两种处理方式：

  1. 导出备份法：先导出该日历作备份 → 删除该日历 → 重建 → 选择性导入备份
  2. 批量删除：Mac 日历切换到列表视图 → 按标题排序 → 全选「XX 生日」事件 → Delete

💡 建议：以后每次导入都选「新建日历」命名为「念念·农历生日」，方便一键管理。

🔄 新增了家人 / 改了年份，怎么更新？

步骤：

  1. 网页上修改名单或年份 → 重新生成 ICS
  2. 日历 App 中右键删除旧的「念念·农历生日」日历
  3. 双击新 ICS 导入 → iCloud 同步

先删旧日历再导入新文件，就不会产生重复事件。
如果多次导入不删旧的，Apple 日历会把同一人生日显示成多个重复事件。

🔒 我的数据会上传到服务器吗？

绝对不会。念念是纯客户端工具：

  • 没有服务器，没有数据库，没有 API
  • 所有计算在浏览器内完成
  • 农历转换库直接内联在 HTML 中，不请求任何 CDN
  • 你可以下载 HTML 到本地，断网也能用
  • 完整开源，代码可审计
📱 支持 Android 手机吗？

念念生成的 .ics 文件是标准日历格式，支持任何平台的日历 App。

Android 上你可以：

  • 用 Google 日历导入（网页版 calendar.google.com → 设置 → 导入）
  • 或者安装开源 App ICSx⁵，用它打开 .ics 文件即可导入系统日历

详细导入指南后续会在 v2 中补充。

📄 支持 Excel (.xlsx) 格式吗？
当前支持 .csv 格式，用 Excel / Numbers / WPS / Google Sheets 都可以打开编辑并另存为 CSV。手机上也推荐用 CSV，方便快捷。
