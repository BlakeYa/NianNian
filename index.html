📖 导入日历指南

下载 .ics 文件后，按你的设备选择导入方式：

💡 如果已经有「念念·农历生日」日历，更新时记得先右键删除旧日历再导入新文件。分多次导入同一个日历，Apple 日历会当成不同事件重复展示。
💻

Mac

  1. 双击下载的 .ics 文件
  2. 日历 App 自动打开
  3. 选择「新建日历」命名为「念念·农历生日」
  4. 点击「好」完成导入
📱

iPhone / iPad

  1. 将 .ics 文件发到微信或邮件
  2. 点击文件 → 选择「用日历打开」
  3. 选择「新建日历」命名为「念念·农历生日」
  4. 点击「完成」→ iCloud 自动同步
🔄

如何更新 / 如何删除

  1. 在网页修改后重新生成并下载 ICS
  2. 日历 App 左侧栏右键删除旧的「念念·农历生日」日历
  3. 双击新 ICS 重新导入到同名日历
  4. iCloud 自动同步所有设备
💡 删除日历只移除生日事件，不影响其他日程。
❓ 常见问题
🤦 导入到错误的日历了怎么办？
导入到了独立的日历 → 直接删除即可。导入到了已有日历 → 导出备份 → 删日历 → 重建。
🔄 新增了家人，怎么更新？
网页改名单 → 重新生成 → 日历中删旧日历 → 导入新文件。先删再导不会产生重复事件。
🔒 数据安全吗？
念念是纯客户端工具：没有服务器、没有数据库、没有 API，所有计算在浏览器内完成，数据永不离开你的设备。
📱 支持 Android 吗？
.ics 是标准格式，Android 上可用 Google 日历或 ICSx⁵ 导入。
📄 支持 Excel 吗？
当前支持 .csv，用 Excel / Numbers / WPS 打开编辑后另存为 CSV 即可。
🔒 隐私承诺
此工具完全运行在你的浏览器中。
